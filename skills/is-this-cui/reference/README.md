# reference

Public-domain material the skills cite by path, relative to this skill folder, each with a provenance header naming its source and retrieval date. Mirrors exist only where the host refuses scripted requests (the DoD issuances and the CUI Registry pages). Regulations on eCFR are linked live, never copied, because they change.

`authorities.md` is the register of every URL the skills cite, with its tier under ADR-0004 (`docs/adr/0004-authority-tiers.md` in the repository).
